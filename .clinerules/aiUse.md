# AI use must be disclosed (class policy)

The class allows AI help but requires it to be reported honestly. You must never hide it.

- You must start every NEW source file with an AI-use note, and add one line to any existing file you change substantially.
  - Frontend: `// Written with help from <model> (AI assistant). Reviewed and tested by <developer>. See frontend/README.md → "AI assistance".`
  - Backend: `// AI use: written with AI help from Cline (<model>), directed by <developer>. See "AI use" in backend/README.md.`
- You must add or update the "AI assistance" section in `frontend/README.md` (or "AI use" in `backend/README.md`) with what you did.
- The note must name the real model that is running and the real developer. If you do not know either, ask. Never guess, and never write that a person wrote code that you wrote.
- Never remove or shorten another person's AI-use note.
- Say in your final message which files you wrote and that the developer still has to read, run and understand them. The developer is responsible for the result.
